# .github

Organization-wide files for [Solid Geeks](https://github.com/SolidGeeks). GitHub uses them in every repository that does not have its own.

| Path | What it is |
|---|---|
| `profile/README.md` | The organization's public profile page. |
| `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md` | Community health files. |
| `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md` | Issue forms and the pull request checklist. |
| `.github/DISCUSSION_TEMPLATE/` | Forms for the [organization's Discussions](https://github.com/orgs/SolidGeeks/discussions), which live in this repository (*Pitch a project*). |
| `workflow-templates/` | Workflows offered under *Actions → New workflow* (first-merge card). |
| `assets/` | Banners, badges, profile header and footer, social previews, hot-linked from the other repositories. |
