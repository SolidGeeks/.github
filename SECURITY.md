# Security policy

Security is part of done. If you found a vulnerability in a Solid Geeks project, thank you. Please report it privately so we can fix it before it is public.

## How to report

1. Open the affected repository on GitHub.
2. Go to **Security → Advisories → Report a vulnerability**.
3. Describe the issue, the affected versions, and how to reproduce it.

Do not open a public issue, pull request or Discord message about it.

## What happens next

- We acknowledge your report within **3 working days**.
- We confirm the issue, agree a fix and a disclosure date with you, and keep you updated.
- Fixes ship in a signed release with an advisory. We credit you, unless you prefer not to be named.

## Supported versions

Each repository lists its supported versions in its own `SECURITY.md`. By default, the latest minor release receives security fixes.

## Scope

In scope: code and releases published under the SolidGeeks organization.
Out of scope: third-party dependencies (report upstream, and tell us so we can update), social engineering, denial of service through volume.

We do not take legal action against good-faith research that follows this policy.
